# Dalvinder Singh — Portfolio

Personal portfolio site for **Dalvinder Singh**, Full Stack Developer (MERN).

Built with **React + Vite + Tailwind CSS v4**. Dark, developer-focused design with
scroll animations, a typewriter hero, and a fully responsive layout.

## Sections
- **Hero** — intro, live-typing roles, résumé download, social links
- **About** — summary + education
- **Skills** — languages, frontend, backend, tools
- **Projects** — featured builds with live demos + source
- **Experience** — work timeline
- **Contact** — email, LinkedIn, GitHub, LeetCode

## Getting started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # preview the production build
```

## Editing content

All content lives in [`src/data.js`](src/data.js) — update your projects, skills,
experience, and links there without touching components.

Your résumé PDF sits at [`public/Dalvinder_Singh_Resume.pdf`](public/Dalvinder_Singh_Resume.pdf)
and is served at `/Dalvinder_Singh_Resume.pdf`.

## Deploy

Ready for **Netlify** (see [`netlify.toml`](netlify.toml)) — same host as the
linked project demos. Push to GitHub and connect the repo, or drag-and-drop the
`dist/` folder.
